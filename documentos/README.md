# Documentos de referência

Os PDFs desta pasta **não são versionados** no repositório, por serem artigos publicados
(direitos autorais). Para o assistente funcionar com a base completa, baixe os artigos abaixo e
coloque os arquivos `.pdf` nesta pasta. O índice de busca é recriado sozinho na próxima execução.

Sem nenhum PDF, o app ainda funciona, mas só com o texto introdutório de `data/`.

## Referências

- GARLAN, David; SHAW, Mary. **An Introduction to Software Architecture.** Carnegie Mellon University, CMU-CS-94-166, 1994.
- KRUCHTEN, Philippe. **The 4+1 View Model of Architecture.** IEEE Software, 1995.
- PERRY, Dewayne E.; WOLF, Alexander L. **Foundations for the Study of Software Architecture.** ACM SIGSOFT Software Engineering Notes, v. 17, n. 4, 1992.
- JANSEN, Anton; BOSCH, Jan. **Software Architecture as a Set of Architectural Design Decisions.** 2005.
